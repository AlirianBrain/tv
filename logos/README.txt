Drop show logos here as PNG (transparent background, at least 600 px wide, no larger than about 200 KB).
Name them as listed in data/show-logos.json, e.g. oud-en-jonk.png, gesels.png, hier-sit-die-manne.png, wie-weet-wat.png.
Then run: python tools/inject_data.py  (the logos are inlined into prototype/foyer-board.html).
A booked studio shows the logo instead of the show name whenever the schedule text contains the 'match' word.
